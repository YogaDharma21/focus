## Overview

Align the mobile timer and sound settings with the extension experience. This removes unused progress indicators, updates the floating timer controls, and adds independently gated sound settings.

## Key Changes

- Remove the placeholder progress bars from the main timer and floating timer card.
- Match the extension floating timer layout with time, task selection, active state, and disabled inactive actions.
- Add master Sound, Music, and Sound Effects settings with persisted state.
- Gate music playback, sound effects, volume sliders, and test controls behind their corresponding settings.
- Fix the About description colors and background for dark mode.
